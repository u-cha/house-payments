# Экраны и информационная архитектура

Список экранов выводится из сценариев [scenarios.md](scenarios.md). Каждый экран
имеет назначение, действия и состояния; инварианты проверяет сервер, экран только
показывает результат и объясняет отказ.

## 1. Навигация

```
Вход / выбор профиля
└── Главная (сводка, напоминания)
    ├── Помещения → Помещение
    ├── Поставщики
    ├── Лицевые счета
    ├── Услуги → Тарифы
    ├── Начисления (импорт CSV — после первой версии)
    ├── Квитанции → Квитанция, Распознавание (S-26), Шаблоны (S-27)
    ├── Платежи → Платёж → Распределение
    ├── Счётчики → Показания
    ├── Напоминания
    ├── Отчёты
    └── Данные (бэкап, экспорт, восстановление)
Настройки
├── Профили и права
├── Напоминания и окна
├── Шифрование и безопасность
└── О приложении, обновления
```

## 2. Экраны

### S-01 — Вход

Выбор профиля и пароль; «Создать файл данных», «Открыть файл». Ошибки: неверный
пароль, файл не найден, файл новее приложения, повреждённый файл. **FR-14.**

### S-02 — Первый запуск

Мастер: выбор папки для файла, создание первого профиля (`owner`), краткая
подсказка «что дальше». **FR-14, FR-16.**

### S-03 — Главная

Сводка: долг и переплата по помещениям, ближайшие напоминания, последние платежи,
быстрые действия. Пустое состояние — подсказка добавить помещение. **FR-08, FR-11, FR-13.**

### S-04 — Помещения

Список с фильтром и поиском, архив. Действия: добавить, открыть, архивировать.
**FR-01.**

### S-05 — Помещение

Карточка: адрес, вид, площадь, доля, лицевые счета, баланс, история документов.
**FR-01, FR-03, FR-08.**

### S-06 — Поставщики

Список: название, тип, контакты, число лицевых счетов. **FR-02.**

### S-07 — Лицевые счета

Список по помещению и поставщику, номер, состояние; ссылка на личный кабинет
поставщика и памятка по передаче показаний/оплате; закрытие при долге запрещено.
**FR-03, FR-19, INV-12.**

### S-08 — Услуги

Справочник услуг: название, единица, категория. **FR-04.**

### S-09 — Тарифы

История тарифов по услуге с датами действия; форма нового тарифа; пересечение
даты отклоняется. **FR-04, INV-04.**

### S-10 — Начисления

Список за период с фильтрами (помещение, услуга, источник), сумма за период.
**FR-05.**

### S-11 — Начисление

Форма: лицевой счёт, услуга, период, сумма, основание; подсказка о копейках.
**FR-05, INV-01, INV-02.**

### S-12 — Импорт CSV (после первой версии)

Мастер: файл → сопоставление колонок → предпросмотр → импорт → отчёт
(`created`/`duplicate`/`rejected`) с причинами. Отложен решением R-06.
**FR-05, QS-03.**

### S-13 — Квитанции

Список за период: статус, сумма, срок оплаты, остаток. **FR-06.**

### S-14 — Квитанция

Карточка: строки с основанием (начисление), итог, срок, статус, оплаченная
информация (дата/комментарий), вложения, история. После `issued` — только чтение;
действия «Аннулировать» (с причиной) и «Сторно»; после `void` — «Выпустить заново».
**FR-06, FR-12, FR-15, INV-03, INV-05.**

### S-15 — Платежи

Список платежей с фильтрами по дате и счёту; сумма распределена/не распределена.
**FR-07, FR-08.**

### S-16 — Платёж и распределение

Форма платежа с выбором квитанций; сохранить без выбранной квитанции нельзя
(INV-22); FIFO или вручную; остаток платежа — аванс; панель отмены распределения
с причиной. Ошибка «превышает остаток» — с пояснением.
**FR-07, FR-08, INV-07…INV-10, INV-22.**

### S-17 — Счётчики

Список приборов: серийный номер, услуга, срок поверки, состояние. **FR-09.**

### S-18 — Показания

Показания по счётчику за периоды; форма ввода; предупреждение об убывании с
подтверждением и причиной; отдельная операция «Заменить счётчик» с начальным
показанием; отметка «передано» со временем автоматически, опционально дата и
способ; срок поверки. **FR-09, FR-10, INV-14, INV-15.**

### S-19 — Напоминания

Список активных и закрытых; действия «выполнено», «отложить», «отключить вид».
**FR-11.**

### S-20 — Отчёты

Период и разрез (услуга, помещение); суммы, график, таблица; экспорт. **FR-13.**

### S-21 — Вложения

Галерея миниатюр, просмотр, прикрепление и удаление с подтверждением; одно фото —
одно вложение, изображение сжимается при добавлении, проверка целостности по
`sha256` (R-01). **FR-12, INV-19.**

### S-22 — Данные

Две автокопии состояния (текущая и предыдущая) при запуске/закрытии с проверкой
целостности, «Сохранить копию», «Восстановить», «Экспорт CSV/XLSX/JSON». Архива
по годам в первой версии нет. **FR-16, QS-07.**

### S-23 — Профиль и права (зона развития)

В первой версии — один профиль `owner`; экран показывает его и пароль. Список
профилей, роли и отключение появятся вместе с многопользовательским режимом;
последний `owner` защищён. **FR-14, INV-16.**

### S-24 — Настройки

Тема, окна напоминаний (за сколько дней), формат дат, язык. Шифрования файла в
первой версии нет (OQ-02). **FR-11, C-04.**

### S-25 — Аудит

История изменений с фильтрами по профилю, дате, типу объекта; причина и
`correlation_id`. Только чтение. **FR-15, INV-17.**

### S-26 — Распознавание квитанции

Загрузка или перетаскивание файла; прогресс обработки; экран подтверждения:
изображение слева, извлечённые поля справа, строки услуг с суммами; уверенность
каждого поля; подсветка низкой уверенности; кнопки «Подтвердить», «Отклонить»,
«Использовать шаблон», «Настроить шаблон» (S-27), если формат незнаком. После
подтверждения — ссылка на созданную квитанцию.
**FR-18, INV-21, QS-11.**

### S-27 — Шаблоны квитанций

Список шаблонов по поставщикам: название, поставщик, версия, дата создания;
действия «Создать по скану», «Открыть», «Новая версия», «Архивировать». Редактор
разметки: скан/PDF образца слева, инструмент обводки областей; список полей
(период, поставщик, лицевой счёт, строки услуг, итог, срок оплаты); предпросмотр
«что распознано» без создания документов; сохранение новой версии — старые
остаются доступны (INV-23). Ошибки: область вне страницы, пустая или
пересекающаяся — подсветить и не сохранять. **FR-20, INV-23, QS-12.**

## 3. Сквозные требования к экранам

1. Все суммы вводятся и показываются в рублях с копейками; хранение — в копейках.
2. Опасные действия требуют подтверждения и причины; причина видна в аудите.
3. Ошибки формулируются действием: что произошло и что сделать.
4. Запрещённое действие роли либо скрыто, либо недоступно с объяснением.
5. Ни один экран не требует сети; индикатор «офлайн» не нужен.
6. Клавиатурная навигация и читаемые подписи — обязательны; проверяются в e2e.
